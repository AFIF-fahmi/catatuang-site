# Kebijakan Privasi CatatUang

Terakhir diperbarui: 18 November 2026

## Data yang diakses

CatatUang meminta izin baca Gmail (gmail.readonly) hanya untuk menemukan dan membaca email notifikasi transaksi dari domain bri.co.id. Email lain tidak diproses dan tidak disimpan.

## Penyimpanan data

Hasil pembacaan email (tanggal, nominal, nama merchant atau penerima, dan nomor referensi) beserta catatan yang dimasukkan pengguna disimpan hanya di perangkat Android pengguna. Aplikasi tidak memiliki server dan tidak mengirim data ke pihak mana pun. Token akses Google dikelola oleh Google Play Services di perangkat.

## Berbagi dan penggunaan data

Data tidak dijual, tidak dibagikan kepada pihak ketiga, dan tidak dipakai untuk iklan. Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

## Menghapus data dan mencabut akses

Pengguna dapat memutus akses Gmail melalui menu Pengaturan di aplikasi atau melalui halaman izin akun Google (myaccount.google.com/permissions). Semua data aplikasi terhapus saat aplikasi di-uninstall.
